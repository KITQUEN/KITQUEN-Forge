# Contributing

Run the Python, Blender, and end-to-end checks from the [README](README.md). Add focused coverage when changing the language, scene semantics, or export behavior. Keep the Blender extension importable without installing MCP in Blender.

Changes to existing command meanings require a language-version decision and a regression test. Update the reference and the matching agent example when adding supported syntax. Use a disposable scene for integration work. Include the Blender version and a minimal Kitlean script when reporting an issue.
